# Condo Website Remake

A modern, responsive condo association website built to replace an outdated website experience with a cleaner, easier-to-navigate interface.

The project focuses on creating a professional public-facing website where residents can quickly access important community information, governing documents, forms, and announcements.

## Features

- Responsive website layout for desktop and mobile users
- Modern navigation system with dropdown menus
- Organized governing document access
- Embedded PDF document viewing
- Downloadable community resources
- Dedicated pages for condo information and services
- Reusable React components for consistent UI
- Clean, maintainable frontend structure

## Tech Stack

Frontend:

- React
- Vite
- JavaScript
- CSS

Backend:

- Java Spring Boot
- Maven

Database: 
- PostgreSQL

### Deployment

- Static frontend hosting
- Cloud-based deployment configuration
